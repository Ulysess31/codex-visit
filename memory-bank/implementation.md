# 구현 기록

## 상태

아직 애플리케이션 코드는 구현하지 않았다. 이 문서에는 확정된 기술 선택과 완료 기능을 기록한다. 검증하거나 채택하기 전의 제안은 미정 항목으로 구분한다.

## 기존 백엔드 확인 사항

- Supabase가 MCP를 통해 연결되어 있다.
- 확인된 `public.guestbook` 컬럼은 `id`(bigint identity 기본 키), `created_at`(timestamptz, 기본값 `now()`), `author`(nullable text), `content`(nullable text)이다.
- `public.guestbook`에는 Row Level Security가 활성화되어 있다.
- `id = 1` 항목이 있다. 내용은 `첫방문입니다.반가와요`로 변경되었다.
- 실제 구현을 위한 최신 스키마, 정책, Realtime 공개 설정, Storage 버킷 및 프레임워크 설정은 아직 다시 확인하지 않았다.

## 확정된 구현 결정

- 데이터베이스, 파일 저장 및 실시간 업데이트에 Supabase를 사용한다.
- 사진·그림·댓글 기능을 추가할 때 기존 방명록 레코드를 보존한다.
- 데이터베이스 변경 전에 현재 스키마와 접근 정책을 확인한다.

## 미정 결정 사항

- 프런트엔드 프레임워크, 패키지 관리자 및 앱 구조
- 이미지 Storage 버킷 이름, 허용 형식 및 크기 제한
- 댓글 테이블 스키마와 정책 세부 사항
- 그림을 직렬화하고 저장하는 방식
- Realtime 구독 생명 주기 및 재연결 동작
- 배포 대상과 필요한 환경 변수

## 구현 완료 기능

- 아직 없음.
