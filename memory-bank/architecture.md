# 시스템 아키텍처

## 제품 개요

방문자가 글, 사진 또는 직접 그린 그림으로 참여하는 실시간 전자 방명록을 만든다. 등록된 방명록은 공유 보드에 여러 색상의 포스트잇 형태로 표시한다. 포스트잇을 열면 전체 내용과 실시간 댓글을 볼 수 있다.

## 구현 기술

- 프런트엔드는 Vite, React, TypeScript로 구성한다.
- 데이터베이스, 이미지 Storage, Realtime 전송은 Supabase를 사용한다.
- Supabase 연결 값은 `VITE_SUPABASE_URL`, `VITE_SUPABASE_PUBLISHABLE_KEY` 환경 변수로 전달한다. 실제 로컬 값은 `.env.local`에 두고 Git에 커밋하지 않는다.

## 사용자 경험

### 방명록 작성

- 방문자가 표시 이름 또는 닉네임과 짧은 글을 입력할 수 있다.
- 사진 업로드와 앱 내 그림판을 지원한다. 글만으로도 방명록을 등록할 수 있다.
- 그림판에는 펜 색상·굵기 선택, 지우개, 전체 지우기 기능을 제공한다.
- 입력 검증, 업로드 진행 상태, 저장 성공 및 실패 상태를 명확하게 보여준다.
- 저장이 완료되면 보드 화면으로 이동한다.

### 공유 보드

- 방명록을 약간씩 다른 각도로 회전된 여러 색상의 포스트잇 카드로 표시한다.
- 작성자, 글 일부, 사진 또는 그림 미리보기, 작성 시각을 표시한다.
- 카드를 선택하면 상세 화면을 연다.
- 새 방명록은 페이지를 새로고침하지 않아도 표시한다.
- 방명록이 없을 때 안내 화면을 제공하며, 데스크톱과 모바일에 맞게 배치한다.

### 방명록 상세 및 댓글

- 전체 글과 사진 또는 그림을 크게 표시한다.
- 작성자와 작성 시각이 포함된 댓글 목록 및 댓글 입력창을 제공한다.
- 새 댓글은 페이지를 새로고침하지 않아도 표시한다.
- 보드로 돌아가거나 다른 방명록으로 이동할 수 있게 한다.

## 백엔드 및 데이터

- 데이터 저장, 파일 저장, 실시간 업데이트에 Supabase를 사용한다.
- 스키마 변경 전에 기존 `public.guestbook` 테이블을 확인한다. 기존 데이터와 구조를 가능한 한 보존한다. 현재 알려진 컬럼은 `id`, `created_at`, `author`, `content`이며, 실제 구현 전 최신 스키마를 다시 확인한다.
- 업로드 사진은 Supabase Storage에 저장하고, 방명록 레코드에는 파일 경로나 URL을 기록한다.
- 방명록 항목과 연결되는 댓글 테이블을 추가한다. 댓글 테이블에는 작성자, 내용, 작성 시각을 둔다.
- 방명록과 댓글 변경을 Supabase Realtime으로 구독한다.
- 공개 방명록에 필요한 최소 권한만 허용하도록 Row Level Security(RLS) 정책을 설정한다.
- 로딩, 저장 오류, 연결 끊김 및 재연결 상태를 처리한다.

## 시각 디자인 및 접근성

- 밝은 배경과 다채로운 포스트잇을 활용해 따뜻하고 친근한 게시판 분위기를 만든다.
- 글과 주요 동작을 읽기 쉽고 찾기 쉽게 배치한다.
- 키보드 조작, 충분한 색상 대비, 이미지 대체 텍스트를 지원한다.

## 완료 기준

- 방문자가 글, 사진 또는 직접 그린 그림으로 방명록을 등록할 수 있다.
- 등록된 방명록이 보드에 포스트잇 카드로 표시된다.
- 방명록을 열어 전체 내용을 보고 댓글을 작성할 수 있다.
- 새 방명록과 댓글이 새로고침 없이 반영된다.
- 데스크톱과 모바일에서 주요 흐름이 동작한다.
